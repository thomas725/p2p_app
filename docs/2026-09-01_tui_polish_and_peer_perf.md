- **Ctrl+I (kitty) / Ctrl+P (universal) opens PeerInfo on a Direct tab; bare Tab always cycles tabs** (this task): on kitty terminals (WezTerm) Ctrl+I arrives as `Char('i')`+CONTROL and opens the DM partner's PeerInfo on Direct tabs. On non-kitty terminals (Konsole) Ctrl+I is byte-identical to the bare `0x09` Tab — and Ctrl+Shift+I collapses to the same byte (`'I'`=0x49 → 0x49&0x1F=0x09) — so neither can be a distinct binding. **Ctrl+? was tried first but Konsole sends a literal `?` (0x3F) for both Shift+ß and Ctrl+Shift+ß** (it does NOT apply the control mask to `?`), so it was indistinguishable from typing — replaced with **Ctrl+P**: `p` is 0x70 and Ctrl+P sends 0x10 (DLE), which crossterm 0.29 decodes as `Char('p')`+CONTROL (the `b'\x01'..=b'\x1A'` arm), and Konsole reliably applies the control mask to letters. The `Char('p')`+CONTROL arm works on **every** terminal (also where kitty is active) and is consumed as a no-op on non-Direct tabs (never typed). Bare Tab now **always cycles tabs on every tab and terminal** — the old bare-Tab-as-Ctrl+I sacrifice on Direct tabs is gone. `Tab`+CONTROL (CSI-u spelling of Ctrl+I) remains a no-op everywhere; `BackTab` cycles backward; plain `i` only opens PeerInfo on the Peers tab (views elsewhere type it). Shortcut bar shows `Ctrl+I/Ctrl+P: Peer Info` on kitty Direct tabs and `Ctrl+P: Peer Info` on non-kitty Direct tabs.

- **Kitty flags are now strictly DISAMBIGUATE-only and popped on exit** (this task, per the user's WezTerm report): the push previously also included `REPORT_ALL_KEYS_AS_ESCAPE_CODES` (flag 8), which makes the terminal report *every* key (letters, shift presses) as CSI-u — unnecessary for separating Ctrl+I, and it left the post-exit shell deluged in `;1u;2u442;1u441;5u442…` junk **because the pushed flags were never popped**. `run_new_tui`'s cleanup now emits `PopKeyboardEnhancementFlags` (kitty `CSI < 1u`) plus a defensive `CSI > 4;0m` (modifyOtherKeys off) — all written before `disable_raw_mode` so the escapes transmit — before `LeaveAlternateScreen`. - **PeerInfo binding is tab-specific**: plain `i` opens PeerInfo only on the **Peers** tab (where there is no text input), so `i` stays typeable in the Chat/DM message boxes. On **Direct/DM** tabs the binding is **Ctrl+I** (plain `i` types into the input). - **Fixed the flaky parallel-target DB race — tests are now independent** (this task): the flake (`cargo test --all-features` → random single `--lib` failure, green on rerun) came from test DB auto-selection: `get_database_url`'s test branch scanned the **shared working directory** for `.db`/`.lock` files, so the lib, bin, and integration test *processes* racing in parallel could delete each other's live lock file (a lock is created atomically but its pid is written a moment later — a peer reading the momentarily-empty file treats it as stale and removes it) and then both select the **same** `sqlite_N.db` → shared rows / "database is locked".
